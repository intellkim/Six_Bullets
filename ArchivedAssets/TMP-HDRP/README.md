# Archived TextMesh Pro HDRP samples

These HDRP-only sample shaders, materials, font and scene are outside `Assets`
because this project uses URP 2D. They were referenced only within this sample
set. Keeping them outside Unity's asset import avoids unsupported HDRP shader
warnings and prevents sample Resources from entering player builds.

Original paths and `.meta` GUIDs are preserved under `Assets/` here. To restore
the sample for an HDRP project, copy that subtree back into the project's Assets.
